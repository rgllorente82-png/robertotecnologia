# Imágenes Educativas - 2º ESO y 4º ESO

## Guía para descargar imágenes de Wikimedia Commons

**Instrucciones generales:**
1. Visita: https://commons.wikimedia.org/
2. Busca el nombre del archivo o las palabras clave
3. Descarga la imagen en máxima calidad disponible (PNG o JPG)
4. Guarda en tu carpeta `/img` con el nombre sugerido
5. Añade a los HTML con figura/figcaption

## INSTRUCCIONES DE DESCARGA

### Método 1: Descarga directa desde navegador
1. Haz clic derecho en la URL → "Guardar enlace como"
2. Descarga en tu carpeta `~/robertotecnologia/img/`
3. Renombra con el nombre sugerido (c1-*, c2-*, etc.)

### Método 2: Busca en Wikimedia Commons
1. Visita: https://commons.wikimedia.org/
2. Busca las palabras clave
3. Verifica que la licencia sea CC BY-SA, CC0 o Public Domain
4. Descarga en máxima calidad disponible

### Método 3: Usar `wget` en terminal
```bash
cd ~/robertotecnologia/img
wget -O c1-design-sketch.jpg "https://commons.wikimedia.org/wiki/File:Engineering_drawing_example.jpg"
```

## INTEGRACIÓN EN HTML

Una vez descargadas, añade a cada tema HTML:

```html
<figure class="foto">
  <img src="../../../img/[nombre-archivo].jpg" width="800" height="600" loading="lazy"
       alt="[descripción en español]">
  <figcaption>[Descripción de la imagen]
    <span class="credito">[Autor] · [Licencia] · <a href="https://commons.wikimedia.org/wiki/File:[Nombre_Wikimedia]" target="_blank">Wikimedia Commons</a></span>
  </figcaption>
</figure>
```
